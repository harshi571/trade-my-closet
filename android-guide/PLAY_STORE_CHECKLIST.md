# Play Store Release Checklist

- [ ] Deploy HTTPS backend and production database
- [ ] Replace development `/api` and `/uploads` paths with production origins
- [ ] Add production app icon, splash, and screenshots
- [ ] Add privacy policy, terms, account deletion, and data safety disclosures
- [ ] Add user reporting, content moderation, and safe exchange guidance
- [ ] Secure file storage and scan uploads
- [ ] Add account recovery, email verification, and abuse prevention
- [ ] Test Android build and app behavior on physical devices
- [ ] Produce signed .aab in Android Studio
- [ ] Complete Google Play Console verification, required testing, and store review

Developer account holder must meet Google's eligibility rules; a minor should work with an eligible parent/guardian or organization for publication.
